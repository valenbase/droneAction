# 小型化低成本云台吊舱设计方案

版本：V0.1
目标：形成一套可进入样机打样的小型化云台吊舱方案，优先低成本、低重量、易调试、可和现有无人机/RK3588/地面站系统集成。

## 1. 设计定位

本方案不对标 DJI H30T、NextVision、Trakka 这类高端多传感器吊舱，而是对标 SIYI A8 mini、Topotek GIP335、Seeed reCamera Gimbal 这类小型化低成本云台。

首版建议做“固定焦可见光三轴云台吊舱”，第二阶段再扩展热成像或小倍率变焦。

### 1.1 首版目标

| 项目 | 目标值 |
| --- | --- |
| 产品形态 | 小型三轴可见光云台吊舱 |
| 载荷 | 固定焦 1080p/2K/4K 摄像头模块 |
| 整机重量 | 100 g 到 180 g，不含外部减振板时优先控制在 150 g 内 |
| 外形尺寸 | 约 70 mm x 60 mm x 85 mm，按相机模组调整 |
| 转角范围 | yaw ±150° 到 ±170°，pitch -90° 到 +30°，roll ±35° 到 ±45° |
| 旋转方式 | 不做 360° 连续旋转，不使用滑环 |
| 稳定精度 | 样机目标 0.1° RMS，优化后争取 0.05° RMS |
| 控制接口 | UART、S.Bus/PWM，预留 MAVLink 或 CAN |
| 视频输出 | 首选 RTSP/IP 摄像头模块；备选 USB UVC、HDMI 或模拟 CVBS |
| 输入电源 | 7 V 到 26 V，兼容 2S 到 6S 电池或机载电源 |
| 平均功耗 | 可见光版 3 W 到 7 W |
| 防护等级 | 首版 IP4X/IP53，量产版再考虑 IP54/IP65 |
| 成本目标 | 首版样机 BOM 约 500 元到 1500 元人民币，随摄像头和加工方式变化 |

### 1.2 不在首版实现的功能

- 不做 360° 无限旋转。
- 不做滑环。
- 不做 10x 以上光学变焦。
- 不做激光测距。
- 不把 IP65、盐雾、军标振动作为首版目标。
- 不追求 0.01° 级稳定精度。

这些功能会显著增加结构、电机、编码器、线缆、热设计和成本压力，不适合低成本小型化首版。

## 2. 总体架构

### 2.1 系统框图

```text
无人机电源 7-26 V
    |
    +-- 云台主控板
    |      |
    |      +-- 3 路无刷电机驱动
    |      +-- 3 路磁编码器
    |      +-- 机体端 IMU，可选
    |      +-- 相机端 IMU，必选
    |      +-- UART/S.Bus/PWM/CAN 接口
    |
    +-- 摄像头模块
           |
           +-- RTSP/USB/HDMI/CVBS 视频输出

机械链路：

机体/减振板
    |
    +-- yaw 方位轴，外轴
           |
           +-- roll 横滚轴，中间轴
                  |
                  +-- pitch 俯仰轴，内轴
                         |
                         +-- 摄像头与相机端 IMU
```

### 2.2 轴系选择

首版采用三轴结构：yaw 外轴、roll 中轴、pitch 内轴。

原因：

- yaw 负责水平指向和跟随机体航向。
- pitch 负责俯仰观察，是最常用任务轴。
- roll 负责画面水平校正，可明显改善小无人机机动和侧风时的画面观感。

若必须进一步压成本和重量，可做两轴版本：yaw + pitch，roll 由电子防抖或图像旋转补偿。但两轴版本在机体横滚时画面水平不稳定，体验明显弱于三轴。

## 3. 机械设计方案

### 3.1 结构布局

推荐结构：

1. 顶部为减振安装板，与无人机或任务舱连接。
2. yaw 电机位于顶部中心，定子固定在减振板，转子带动下方云台主体。
3. roll 电机布置在 yaw 转子下方一侧或后侧，带动 pitch 框架横滚。
4. pitch 电机布置在摄像头两侧之一，另一侧使用轴承支撑。
5. 摄像头模块、相机端 IMU、镜头前盖组成内层载荷。

### 3.2 关键机械原则

#### 重心

每个旋转轴的重心偏差应尽量小：

| 轴 | 重心偏差目标 |
| --- | --- |
| pitch | 小于 1.5 mm，最高优先级 |
| roll | 小于 2 mm |
| yaw | 小于 3 mm |

pitch 轴重心偏差是首版最容易导致发热、抖动和电机啸叫的问题。设计时必须给摄像头模组预留前后/上下微调空间。

#### 走线

首版不使用滑环，使用高柔软排线或硅胶线，并限制 yaw 角度。

走线原则：

- yaw 线束从旋转轴附近通过，形成大半径松弛环。
- pitch 线束尽量靠近 pitch 轴心，减少线缆反扭矩。
- 避免硬 FPC 在轴外偏心弯折。
- 线缆必须固定两端，中间只允许受控弯曲。
- 线束预留寿命测试，至少完成 5 万次角度循环后无断线和明显扭矩变化。

#### 轴承与同轴度

首版可采用小型深沟球轴承，成本低、采购容易。pitch 轴建议两侧支撑，一侧电机，一侧轴承。

建议指标：

| 项目 | 目标 |
| --- | --- |
| pitch 轴同轴度 | 小于 0.05 mm |
| roll 轴同轴度 | 小于 0.08 mm |
| yaw 轴端面跳动 | 小于 0.08 mm |
| 轴向虚位 | 小于 0.1 mm |
| 装配后空载摩擦 | 用手轻拨可顺滑回摆，无明显卡点 |

若使用 3D 打印件，轴承孔需要二次铰孔或使用嵌件，不能完全依赖打印精度。

### 3.3 材料与加工

首版推荐两种路线：

| 路线 | 用途 | 优点 | 缺点 |
| --- | --- | --- | --- |
| SLS 尼龙/碳纤尼龙 + 金属轴套 | 快速样机 | 成本低、修改快、重量轻 | 精度和刚度有限 |
| CNC 6061 铝合金主体 + 塑料外壳 | 接近量产 | 刚度高、散热好、装配稳定 | 成本高、改版慢 |

建议开发顺序：

1. 第一轮用 3D 打印验证空间、重心和走线。
2. 第二轮将 pitch 支架、roll 支架、yaw 连接座改为 CNC 铝件。
3. 外壳最后再做，避免早期外观约束影响调试。

### 3.4 减振方案

小型无人机的振动会直接影响 IMU 和图像稳定。首版使用四点阻尼球减振。

建议：

- 减振板和云台主体之间使用 4 个小型橡胶阻尼球。
- 阻尼球不能过软，否则机体加速时云台整体晃动。
- 增加机械限位，防止坠落或急停时阻尼球拉断。
- IMU 滤波和减振结构需要一起调试，不能只靠软件滤波。

## 4. 电机与编码器方案

### 4.1 电机类型

采用直驱无刷云台电机，不使用舵机、齿轮箱或步进电机。

推荐参数：

| 轴 | 电机建议 | 连续扭矩目标 | 备注 |
| --- | --- | --- | --- |
| pitch | 1804/2004 级低 KV 云台电机 | 大于 0.02 N·m | 载荷最敏感，优先平衡 |
| roll | 1806/2204 级低 KV 云台电机 | 大于 0.03 N·m | 需要带动内层 pitch 组件 |
| yaw | 2204/2206 级低 KV 云台电机 | 大于 0.04 N·m | 带动全部下挂质量 |

低成本采购时可以使用现成云台电机；如果后续量产，再定制空心轴、低齿槽转矩、高极数电机。

### 4.2 扭矩估算

电机需要克服三类负载：

```text
T_required = J * alpha + m * g * d + T_cable + T_friction
```

其中：

- `J`：绕该轴转动惯量。
- `alpha`：期望角加速度。
- `m`：该轴带动质量。
- `d`：重心相对轴线偏差。
- `T_cable`：线缆反扭矩。
- `T_friction`：轴承和装配摩擦。

以 pitch 轴为例：

```text
m = 0.065 kg
d = 0.0015 m
m * g * d = 0.065 * 9.81 * 0.0015 = 0.00096 N·m
```

理论重力矩不大，但考虑线缆、摩擦、动态机动、制造误差和温升，电机连续可用扭矩建议留 10 倍以上裕量。

### 4.3 编码器

首版推荐磁编码器。

| 方案 | 分辨率 | 成本 | 建议 |
| --- | --- | --- | --- |
| AS5600 | 12 bit | 低 | 可用于验证样机，稳定精度要求不高时可用 |
| MT6701 | 14 bit | 中低 | 推荐首版使用，性价比高 |
| AS5047P/AS5048A | 14 bit | 中 | 更成熟，成本略高 |
| 光电编码器 | 高 | 高 | 首版不建议 |

14 bit 编码器理论角度分辨率约为：

```text
360° / 16384 = 0.022°
```

考虑噪声和装配偏心，实际不能简单等同稳定精度，但足够支撑 0.05° 到 0.1° 级样机目标。

### 4.4 磁铁与装配

- 使用径向充磁或直径方向充磁磁铁，必须匹配编码器芯片要求。
- 磁铁中心与芯片中心偏差建议小于 0.2 mm。
- 磁铁与芯片间距按芯片数据手册控制，通常为 0.5 mm 到 2.5 mm。
- 编码器零位需要软件标定，机械装配不追求绝对零位。

## 5. 电气设计方案

### 5.1 主控板架构

推荐使用一块云台主控板，集成电源、MCU、三路电机驱动、接口保护和编码器接口。

推荐器件方向：

| 模块 | 推荐 |
| --- | --- |
| MCU | STM32G431 / STM32G474 / STM32F405 |
| 电机驱动 | DRV8313、DRV8316、MP6540 或三相半桥方案 |
| IMU | ICM-42688-P、BMI088、ICM-20602 |
| 编码器 | MT6701、AS5048A、AS5600 |
| 电源 | 7-26 V 输入，5 V buck，3.3 V LDO 或 buck |
| 接口 | UART、S.Bus/PWM、CAN 预留、USB 调试 |

STM32G4 系列适合电机控制，ADC、定时器和 FOC 支持较好。若先用开源生态快速验证，可用 SimpleFOC 思路；但最终产品建议固件自主掌控。

### 5.2 电源设计

电源链路：

```text
7-26 V 输入
    |
    +-- TVS/反接/保险丝
    |
    +-- 5 V buck，供摄像头、电机驱动逻辑、外设
    |
    +-- 3.3 V，供 MCU、IMU、编码器
```

设计要求：

- 输入端必须有反接保护和浪涌抑制。
- 电机电源和 IMU/编码器电源要做滤波隔离。
- IMU 供电要干净，避免电机 PWM 噪声耦合。
- 摄像头供电单独滤波，避免视频噪声和重启。

### 5.3 PCB 建议

- 首版建议 4 层板。
- 电机相线尽量短，远离 IMU 和编码器信号。
- 三相驱动区域和传感器区域分区。
- IMU 不建议放在主控板上作为唯一姿态传感器，应放在相机端刚性连接处。
- 主控板可放机体侧或 yaw 旋转侧。若放旋转侧，走线更简单；若放机体侧，散热和维护更方便但穿轴线多。

首版建议：主控板放 yaw 旋转侧，减少跨 yaw 轴线缆数量。

## 6. 固件与控制方案

### 6.1 控制层级

```text
电机 FOC/力矩控制：8 kHz 到 20 kHz
    |
速度/位置内环：1 kHz 到 2 kHz
    |
姿态稳定环：500 Hz 到 1 kHz
    |
命令/接口层：50 Hz 到 100 Hz
```

### 6.2 传感器融合

首版可采用：

- 陀螺仪积分获取短时姿态变化。
- 加速度计校正低频漂移。
- 编码器提供电机机械角和轴角反馈。
- 机体 MAVLink 姿态数据可作为可选前馈。

不建议首版依赖磁力计。无人机电机、电调和电源线会严重干扰磁场。

### 6.3 工作模式

| 模式 | 说明 |
| --- | --- |
| lock | 锁定地理/惯性方向，机体运动时云台保持视线 |
| follow | 跟随机体 yaw，pitch/roll 稳定 |
| fpv | 低增稳或跟随模式，画面更接近飞行视角 |
| recenter | 回中 |
| rate | 角速度控制，适合摇杆 |
| angle | 角度控制，适合任务指向 |
| calibration | 标定模式 |

### 6.4 标定流程

首版必须设计可重复的标定流程：

1. 电机相序识别。
2. 电机极对数识别。
3. 编码器方向识别。
4. 编码器零位标定。
5. IMU 零偏标定。
6. 三轴机械中位标定。
7. pitch/roll 水平校准。
8. PID 参数保存。

没有标定流程的云台很难进入稳定调试。

### 6.5 保护逻辑

- 过流保护。
- 电机堵转保护。
- 编码器丢失保护。
- IMU 数据异常保护。
- 姿态发散保护。
- 过温降额。
- yaw/pitch/roll 软件限位。
- 掉电或通信丢失后保持/回中策略。

## 7. 通信与视频集成

### 7.1 云台控制接口

首版建议支持三类控制：

| 接口 | 用途 |
| --- | --- |
| UART | 主接口，和 RK3588/飞控/上位机通信 |
| S.Bus/PWM | 兼容遥控器或飞控通道 |
| USB | 调试、升级、参数配置 |

CAN 和 MAVLink 可预留，不一定首版完成。

### 7.2 建议命令集

内部二进制协议或 JSON 均可。若直接和 RK3588 集成，建议用简化 JSON 或 MAVLink。

建议抽象命令：

| 命令 | 参数 | 说明 |
| --- | --- | --- |
| `gimbal_recenter` | 无 | 回中 |
| `gimbal_set_mode` | `lock/follow/fpv/rate/angle` | 设置模式 |
| `gimbal_angle` | `yaw_deg,pitch_deg,roll_deg` | 角度控制 |
| `gimbal_rate` | `yaw_dps,pitch_dps,roll_dps` | 角速度控制 |
| `gimbal_zoom` | `value` | 预留，固定焦首版不实现 |
| `gimbal_snapshot` | 无 | 预留，相机拍照 |
| `gimbal_record` | `start/stop` | 预留，录像控制 |
| `gimbal_status` | 无 | 查询状态 |

若和当前 DroneAction 项目集成，可在 RK3588 端新增云台控制通道，由 PC 端 UI 或任务逻辑发送云台命令；视频仍沿用 RTSP。

### 7.3 视频输出

低成本首版推荐 RTSP/IP 摄像头模块，理由：

- 和当前项目默认 RTSP 视频链路一致。
- RK3588/PC 端接入简单。
- 不需要云台主控处理视频。

备选方案：

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| RTSP/IP 模块 | 系统集成简单 | 延迟和码率受模块影响 |
| USB UVC | 成本低，接入方便 | 线缆和主机依赖较强 |
| HDMI | 画质好，通用 | 线缆硬、体积大，不适合小云台 |
| MIPI CSI | 延迟低，适合 RK3588 | 结构和线缆设计难度高 |
| CVBS | 低成本、低延迟 | 画质低 |

## 9. 样机研发计划

### P0：方案冻结与关键件选型，1 周

输出：

- 目标规格冻结。
- 摄像头模块尺寸和重量确认。
- 电机、编码器、IMU、驱动芯片选型。
- 三轴空间布局草图。
- 风险清单。

通过标准：

- 总重量估算小于 180 g。
- pitch 轴重心可通过结构调节压到 1.5 mm 内。
- 线缆路径不穿越高摩擦区域。

### P1：开架结构样机，2 到 3 周

输出：

- 无外壳三轴结构样机。
- 临时控制板或开发板。
- 电机可闭环转动。
- IMU 和编码器数据可实时读取。

通过标准：

- 三轴可独立闭环。
- pitch 轴无明显自激振荡。
- 回中和角度控制可用。
- 持续运行 30 分钟不过温。

### P2：稳定控制样机，3 到 5 周

输出：

- 三轴姿态稳定。
- UART/S.Bus 控制。
- RTSP 视频链路。
- 基础调参工具。

通过标准：

- 手持晃动下画面明显稳定。
- 无人机低速悬停时可用。
- 稳定误差进入 0.1° 到 0.2° 级。
- 电机温升可控。

### P3：封装与机载测试，4 到 6 周

输出：

- 带减振座和简易外壳的吊舱。
- 与 RK3588/飞控/地面站联调。
- 机载振动和飞行测试报告。

通过标准：

- 起飞、悬停、平飞、转向时无发散。
- 视频链路稳定。
- 云台命令响应稳定。
- 线缆无干涉和异常磨损。

## 10. 测试方案

### 10.1 台架测试

| 测试 | 方法 | 目标 |
| --- | --- | --- |
| 空载转动 | 三轴单独转动 | 无卡点、无异常电流 |
| 重心测试 | 断电后看各轴自然偏转 | pitch 轴接近平衡 |
| 编码器测试 | 旋转一圈读数 | 无跳变、无反向 |
| IMU 静态噪声 | 静置采样 5 分钟 | 零偏稳定 |
| 电机温升 | 运行 30 分钟 | 外壳不过热，驱动不过温 |
| 限位测试 | 指令打满 | 不撞结构、不拉线 |

### 10.2 振动测试

先用简易方式：

- 固定在无人机机臂附近，电机上电但不起飞。
- 逐步提升油门，记录 IMU 频谱。
- 更换阻尼球硬度和预紧，比较画面和 IMU 数据。

后续再做振动台测试。

### 10.3 飞行测试

飞行测试顺序：

1. 桨叶拆除，地面联调。
2. 室外固定上电测试。
3. 低高度悬停。
4. 低速前后左右运动。
5. yaw 转向。
6. 中速飞行。
7. 长时间运行和返航降落。

每次测试记录：

- 云台 IMU 原始数据。
- 三轴角度和电机电流。
- 控制模式和目标角。
- 视频录像。
- 电机和驱动温度。

## 11. 风险与对策

| 风险 | 表现 | 对策 |
| --- | --- | --- |
| pitch 重心偏差 | 电机发热、低频抖动 | 结构上预留相机调节槽，调平后再锁紧 |
| 线缆反扭矩 | 小角度回弹、控制不准 | 使用超软线，靠近轴线走线，限制 yaw 角 |
| 轴承/支架不同轴 | 卡滞、啸叫、电流高 | 提高关键件加工精度，轴承孔二次加工 |
| 电机齿槽转矩大 | 低速抖动 | 选择云台专用低齿槽电机 |
| IMU 振动过大 | 姿态发散、画面抖 | 减振和滤波一起调，必要时换 IMU 位置 |
| 编码器偏心 | 角度周期误差 | 控制磁铁同心度，做软件误差补偿 |
| 散热不足 | 驱动过温 | 降低电机电流，驱动区铺铜，金属结构导热 |
| 视频线太硬 | 影响 pitch/roll | 首版优先 RTSP 模块，减少跨轴高速线 |
| 过早做外壳 | 调试困难 | P1/P2 保持开架结构，P3 再封装 |

## 12. 推荐首版技术组合

若以成功率和成本平衡为优先，建议首版采用：

- 三轴直驱无刷云台结构。
- yaw 限位 ±160°，不使用滑环。
- 固定焦 RTSP/IP 摄像头模块。
- STM32G431 主控。
- 三路小功率无刷驱动。
- 三路 MT6701 或 AS5048A 磁编码器。
- 一个相机端 ICM-42688-P 或 BMI088 IMU。
- UART + S.Bus/PWM 控制。
- USB 调试和固件升级。
- 四点阻尼球减振。
- 3D 打印结构验证，CNC 铝件做第二版关键承力件。

## 14. 结论

低成本小型化吊舱的最优首版路线是：固定焦可见光、三轴增稳、无滑环、限位 yaw、RTSP 视频、UART/S.Bus 控制。该路线能把主要风险集中在机械重心、线缆反扭矩、三轴电机控制和抗振调参上，避免被光学变焦、热成像、激光测距和高等级防护拖慢。

首版不要追求功能完整，而要追求机械和电控闭环可靠。只要三轴结构、重心、编码器、IMU 和控制环跑通，后续扩展双光、AI 跟踪和更高防护等级才有稳定基础。
